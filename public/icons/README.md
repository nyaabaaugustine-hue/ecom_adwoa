# PWA Icons

Replace the icon files in this folder with your real app icons.
Required sizes: 72, 96, 128, 144, 152, 192, 384, 512 (all PNG).

You can generate all sizes from one 512x512 master icon using:
https://www.pwabuilder.com/imageGenerator

Or use Figma / any design tool to export at each size.

The icon should have:
- A pink/amber gradient background (#ec4899 → #f59e0b)
- The "A" letter in white serif font (or your logo)
- Rounded corners (for maskable icons, keep the logo within the "safe zone" — center 80%)
